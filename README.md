# 🚀 SmartHire – AI-Powered Resume Analysis & Job Recommendation

SmartHire is an AI-powered career assistance platform that analyzes resume content, predicts the most suitable job category, recommends relevant job roles, and identifies skills that the candidate already has and needs to improve.

## ✨ Features

- 📄 Resume Content Analysis
- 🤖 AI-Based Job Category Prediction
- 💼 Job Recommendations
- 📊 Skill Gap Analysis
- 🎯 Matched Skills Identification
- 📚 Skills-to-Improve Suggestions
- 🌐 Professional Web Interface
- ⚡ Fast and Easy Resume Analysis

## 🧠 Machine Learning

SmartHire uses Natural Language Processing and Machine Learning techniques to analyze resume text.

### Technologies Used

- Python
- Flask
- Pandas
- NumPy
- Scikit-learn
- TF-IDF Vectorization
- Machine Learning
- HTML
- CSS
